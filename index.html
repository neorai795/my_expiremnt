My Experiment

This page explains every command that was run to create this project, back it up with git, and publish it to a new public GitHub repository.

1. Check GitHub login and git identity

gh auth status
git config --global user.name
git config --global user.email

Confirms the GitHub CLI (gh) is logged in and that git knows who is making commits.

2. Create the folder

mkdir my_expiremnt
cd my_expiremnt

mkdir creates the new folder and cd moves into it.

3. Create this HTML file

cat > index.html <<'EOF'
...this page...
EOF

Writes index.html (this file) using a shell heredoc.

4. Initialize git and commit (the backup)

git init -b main
git add index.html
git commit -m "Add index.html explaining the commands"

git init turns the folder into a repository on branch main, git add stages the file, and git commit saves a snapshot of it in history.

5. Create the public GitHub repo and push

gh repo create my_expiremnt --public --source=. --remote=origin --push

Creates a new public repository on GitHub, links it as the origin remote, and pushes the main branch there.
